# Teste Prático QA 01 - API Testing Restful Booker

Este projeto contém a documentação e os testes realizados na API **Restful Booker**, como parte de um desafio prático para uma vaga de QA.

O objetivo foi validar os principais fluxos da API, contemplando autenticação, criação, consulta, atualização e exclusão de reservas, além de testes negativos, validações de campos obrigatórios, análise de bugs, métricas, riscos e sugestões de melhoria.

---

## API testada

**Restful Booker**

Base URL utilizada:


https://restful-booker.herokuapp.com


## Ferramentas Utilizadas

```txt
| Ferramenta                | Finalidade                                                     |
| ------------------------- | -------------------------------------------------------------- |
| Postman                   | Execução dos testes de API.                                    |
| Postman Collection Runner | Execução organizada dos requests.                              |
| Postman Environment       | Controle de variáveis como `BASE_URL`, `TOKEN` e `BOOKING_ID`. |
| Markdown                  | Documentação dos testes, bugs, métricas e riscos.              |
| GitHub                    | Hospedagem do projeto e entrega do desafio.                    |
| Capturas de tela          | Evidências dos resultados obtidos.                             |
```
